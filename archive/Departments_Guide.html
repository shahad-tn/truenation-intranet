STEP-BY-STEP
1
Page Banner
Native Sites
  1. Open the Departments page in Sites editor
  2. Click the Header section → set background to #7C1316
  3. Heading: DEPARTMENTS → color #F2EDE4
  4. Subtitle: All departments across Apostles, Deacons, and Judges branches.
2
Branch Headings (×3)
Native Sites
  1. Add a new section → insert a Heading 2 text block
  2. Type APOSTLES BRANCH → color #7C1316
  3. Below it, add a Normal text block for the subtitle
  4. Repeat for DEACONS BRANCH and JUDGES BRANCH
💡 Each branch heading gets its own section so you can embed the dept cards directly below it.
3
Department Cards (3 embeds)
3 Embed Files
  1. Below APOSTLES BRANCH heading → Insert → Embed → Embed code → paste departments-apostles.html
  2. Below DEACONS BRANCH heading → Insert → Embed → Embed code → paste departments-deacons.html
  3. Below JUDGES BRANCH heading → Insert → Embed → Embed code → paste departments-judges.html
  4. Update each card's href with the URL of that dept's Sites page

STEP-BY-STEP — Repeat for all 20 pages
1
Department Banner
Native Sites
  1. Create a new Sites page under Departments
  2. Click Header → background #7C1316, text color #F2EDE4
  3. Add branch badge as small text above the heading: e.g. DEACONS BRANCH
  4. Heading: department name in ALL CAPS
  5. Subtitle: one-sentence description of the department
2
Department Lead
Native Sites
  1. Add a new section below the banner
  2. Add Heading 3: DEPARTMENT LEAD → color #7C1316
  3. Add Normal text with the lead's name and title
  4. For co-leads, list both names (e.g. Fellowship & Services: Deacons Kabash/Kahan)
3
Sub-group Cards + Actions
Custom Embed
  1. Add Heading 2: TEAMS & SUB-GROUPS → color #7C1316
  2. Below it: Insert → Embed → Embed code
  3. Paste dept-subgroup-cards.html
  4. Edit the card names, descriptions, and lead names for this department
  5. Update Chat Space URL, Drive folder URL, and email address
  6. For depts with NO sub-groups (Security, Maintenance): delete the card grid, keep only the action buttons
💡 The Feast Committee page under Fellowship & Services needs 7 sub-group cards: Beverages, Ceremonial, Culinary, Decor, Desserts, Sacrificial Cooking, Serving & Catering.
4
Calendar + Drive (optional)
Built-in Sites
  1. Only add for depts with regular events (Fellowship, T.E.L.A., Production, IT)
  2. Add Heading 2: DEPARTMENT CALENDAR
  3. Insert → Calendar → select this dept's Google Calendar
  4. Add Heading 2: SHARED DOCUMENTS
  5. Insert → Drive → select this dept's Drive folder

STEP-BY-STEP — Repeat for each sub-group
1
Sub-group Banner
Native Sites
  1. Create a new Sites page nested under the department (e.g. IT/Info Tech → Logistics)
  2. Set header background to #7C1316, text color #F2EDE4
  3. Add two small badge labels above the heading: DEACONS BRANCH and IT / INFO TECH
  4. Heading: sub-group name in ALL CAPS (e.g. LOGISTICS)
  5. Subtitle: one-sentence description of the sub-group's purpose
2
Sub-group Lead
Native Sites
  1. Add a new section below the banner
  2. Add Heading 3: SUB-GROUP LEAD → color #7C1316
  3. Add Normal text with the lead's name and role
  4. Format: Name · Sub-group Lead · Department Name
3
Responsibilities
Native Sites
  1. Add Heading 2: RESPONSIBILITIES → color #7C1316
  2. Below it, add a Bulleted list with this sub-group's core duties
  3. Keep to 4–6 bullets — these should be specific and actionable
💡 Use Sites' native bullet list — no embed needed. This section is purely text content.
4
Communication & Files
Custom Embed
  1. Add Heading 2: COMMUNICATION & FILES → color #7C1316
  2. Insert → Embed → Embed code → paste dept-subgroup-cards.html
  3. Delete the sub-group card grid — keep only the action buttons section
  4. Update Chat Space URL to this sub-group's specific space
  5. Update Drive folder URL to this sub-group's folder
  6. Update email to this sub-group's address (if it has one, otherwise remove)
💡 Sub-groups reuse the same embed file as Level 2 — just delete the cards grid and keep the buttons.
5
Calendar (optional)
Built-in Sites
  1. Only add if this sub-group has its own Google Calendar
  2. Add Heading 2: SUB-GROUP CALENDAR
  3. Insert → Calendar → select this sub-group's calendar
