STEP-BY-STEP INSTRUCTIONS
1
Welcome Banner
Native Sites
  1. In Sites editor, click the Header section at the top of the page
  2. Click "Header type" → choose "Banner" or "Cover"
  3. Click Background → Custom color → enter #7C1316
  4. Type your heading: TRUE NATION ISRAELITE CONGREGATION
  5. Set text color to #F2EDE4 (cream)
  6. Add subtitle text below: Our people. Our purpose. One community.
💡 The Header section in Sites auto-spans full width — no embed needed. This is what gives you the full-bleed Wine background.
2
Announcements Section
Native + Embed
  1. Click Insert → Section to add a new content section
  2. Add a Text block → type ANNOUNCEMENTS → set style to Heading 2
  3. Set text color to #7C1316
  4. Below the heading, click Insert → Embed → Embed code
  5. Paste the contents of home-announcements.html
  6. Resize the embed height to fit the content
3
Quick Links Grid
Native + Embed
  1. Add a new section (click the + between sections)
  2. Add a Heading 2 text block → type QUICK LINKS
  3. Set color to #7C1316
  4. Below the heading, click Insert → Embed → Embed code
  5. Paste the contents of home-quick-links.html
  6. Update each tile's href="#..." with real page URLs
💡 The quick links embed has NO outer padding or max-width — it fills the full section width automatically.
4
Upcoming Events Calendar
Built-in Sites
  1. Add a Heading 2 → type UPCOMING EVENTS
  2. Click Insert → Calendar (Sites has a built-in Calendar widget)
  3. Select your TNIC All-Org Events calendar
  4. Set display to Agenda view for best mobile experience
  5. The Sites calendar embed resizes natively — no custom code needed
💡 Use Sites' built-in calendar embed here rather than a custom iframe — it handles auth, mobile, and width automatically.
