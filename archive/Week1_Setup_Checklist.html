Week 1 Setup Checklist

True Nation Intranet — Phase 1: Foundation + Home
PROGRESS 0 / 11 complete
A
Google Admin Setup
Configure Groups, permissions, and build team access
Verify all 10 Google Groups exist
Go to Google Admin Console → Directory → Groups. Confirm these exist: everyone@, tn-admin@, leadership@, finance@, it@, tela@, moreh@, deacons@, apostles@, judges@ (all @truenation.org)
Google Admin Console
Add build team members to tn-admin@
In Groups, open tn-admin@truenation.org → Add members. Every build team member gets immediate edit access to Sites, Drive, and AppSheet admin.
Google Admin Console
Assign Delegated Admin roles to helpers
Admin Console → Account → Admin roles → Create custom role scoped to Groups management + Sites/Drive. Assign to build team helpers (not full Super Admin).
Google Admin Console
B
Site Structure
Set up navigation, pages, and permissions on portal.truenation.org
Set up 8-section navigation
In Google Sites editor: create pages for Home, Our People, Departments, T.E.L.A., Locations, Calendar & Events, Resources, Leadership Hub. Arrange in this exact order in the nav.
Google Sites
Set page permissions
Leadership Hub → Share → Restrict to leadership@truenation.org only. All other pages → everyone@truenation.org. (Sites → Sharing settings per page)
Google Sites
Tip
Google Sites page-level restrictions work via "Published page viewers." Set the site published to everyone@, then restrict the Leadership Hub page to leadership@.
C
Brand + Content
Apply brand CSS and build the Home page using the provided templates
Embed brand CSS on every page
Insert → Embed → Embed Code → paste the contents of tnic-brand-styles.html at the TOP of every page. This loads fonts and brand variables.
Google Sites
Build Home page from template
Embed home-page.html below the brand styles. Replace all [REPLACE] URLs: update quick link hrefs with your actual Google Sites page URLs, and replace the calendar iframe src with your All-Org Events calendar ID.
Google Sites
Embed AppSheet directory on "Our People"
Go to the Our People page → Insert → Embed → paste the AppSheet embed URL for the existing staff directory. Test search, filters, and tap-to-call on mobile.
Google Sites
D
Calendars + Drive
Create shared calendars and set up the Admin Handoff document
Create All-Org Events and Feast Days calendars
In Google Calendar → Create new calendar → "TNIC All-Org Events" and "TNIC Feast Days." Share both with everyone@truenation.org (See all event details). Copy the Calendar IDs for embedding.
Google Calendar
Save Admin Handoff doc to Drive
Upload Admin_Handoff_Document.docx to a Drive folder shared only with tn-admin@truenation.org. Fill in any [placeholder] values with actual URLs as you create resources.
Google Drive
E
Mobile QA
Test everything on actual phones before moving to Week 2
Critical
The majority of TNIC staff access from mobile. Every item below must pass on both iOS and Android before Week 1 is complete.
Mobile test: Home, Our People, navigation
On a real phone: verify no horizontal scroll, tap targets are large enough (44x44px min), banner text is readable, quick links grid stacks properly, calendar embed loads, directory search/filter works, tap-to-call and tap-to-email work.
iOS + Android
