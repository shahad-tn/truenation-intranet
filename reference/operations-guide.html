Overview

At a Glance

Onboarding is a two-stage process. Stage 1 is public-facing — anyone can fill out the form. Stage 2 requires a True Nation Google account and happens after the account is created.

Stage 1 · Public
Vercel Onboarding Form
truenation.vercel.app/onboarding

New staff fill out a short public form — no login required. The system provisions a @truenation.org Google account and emails the new staff member their credentials.

→
Stage 2 · Authenticated
Google Sites Profile Setup
truenation.vercel.app/setup

After logging in with their new account, staff complete the full 8-step profile — emergency contacts, household info, ID upload, skills, and ministry interests.

Access Control Policy

Always use Google Groups for access control. Never share individual pages, folders, or sheets with personal email addresses — always use the group address. Never create a shared generic login (e.g. admin@truenation.org). Individual accounts give you a full audit trail and enable clean offboarding.

Onboarding Flow

How a New Staff Member Joins

1
Send Them the Onboarding Link

Share truenation.vercel.app/onboarding via email, text, or in person. No account needed to access the form.

2
They Fill Out the Short Form

Legal name, preferred name, personal email address, desired username, and campus/location. This is brief by design — Stage 2 collects the rest.

3
The System Creates Their Google Account

A @truenation.org Google Workspace account is provisioned automatically. Credentials and the profile setup link are emailed to their personal address.

If they don't receive the email: Ask them to check spam. An admin can also manually resend from the Google Admin Console (admin.google.com → Users → select user → Security → Reset password).
4
They Log In & Complete Their 8-Step Profile

At truenation.vercel.app/setup, staff complete the full profile using their new @truenation.org account.

5
Admins Assign Their Role

An admin opens the Staff Sheet and fills in: branch, department, cost center, and employment type. The directory reflects the update on the next sync.

Why Two Stages?

The short public form gets a new person into the system quickly, even from a phone at an event. The full profile setup is done on their own time, after they have their login. This prevents bottlenecks and keeps the onboarding form simple to share.

Admin Reference

Common Admin Tasks

Add a New Admin
  1. Go to admin.google.com and locate the user
  2. Add them to the tn-admin@truenation.org Google Group
  3. Grant Delegated Admin role (Groups + Sites minimum)
  4. Brief them on these access control policies
Edit a Profile (Self-Service)
  1. Sign in at truenation.vercel.app/setup with your @truenation.org account
  2. Navigate to the step you want to update
  3. Save the section — the Staff Sheet updates automatically
Edit a Profile (Admin)
  1. Open the Staff Sheet (shared with tn-admin group)
  2. Find the staff member's row
  3. Edit the relevant cell(s) directly
  4. Directory updates on the next daily sync (or trigger manually)
Remove Someone Who Has Left
  1. Suspend their Google account in Admin Console (do not delete — preserves audit trail)
  2. Move their row to the Former Staff tab in the Staff Sheet
  3. Remove them from all Google Groups
  4. Revoke any shared Drive or Sites access as needed
Reset Someone's Password
  1. Go to admin.google.com → Users
  2. Select the user → Security tab
  3. Click Reset Password
  4. Send them the temporary password; ask them to change it on first sign-in
Trigger a Manual Directory Sync
  1. Go to script.google.com → TNIC StaffDirectory project
  2. Select the syncWorkspaceToSheet function
  3. Click Run → confirm any permissions prompted
  4. Check the Audit Log tab in the Staff Sheet for confirmation
When Something Looks Wrong

Troubleshooting

Symptom Likely Cause & Fix
Onboarding form won't submit Username collision — the desired username already exists. Ask them to choose a different one and resubmit.
Didn't receive the welcome email Check spam folder first. If still missing, admin can manually reset the password from Admin Console and provide credentials directly.
Profile setup page is blank or shows an error User is signed in with their personal Gmail, not their @truenation.org account. Ask them to sign out and sign back in with the correct account.
Address autocomplete not working on profile form Google Maps API key may be expired or over quota. Contact the IT lead (shahad@truenation.org) to check the API key in the Vercel dashboard.
ID photo upload fails File is too large (limit: 4 MB). Ask the user to compress the image and retry. JPG format recommended.
Staff member can't see the directory They are not signed in with a @truenation.org account, or their account hasn't been added to the correct Google Group. Verify in Admin Console.
New entry not showing in the directory after profile setup The daily sync hasn't run yet. Trigger a manual sync from Apps Script (see Common Admin Tasks), or wait until the next scheduled run.
Audit Log tab is not updating The Apps Script trigger may have been deleted or paused. Go to script.google.com → Triggers and confirm the daily sync trigger is active.
