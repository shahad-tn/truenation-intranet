Staff Directory — Migration Guide

Adapting your existing True Nation Staff Data sheet for the Dashboard
The good news: Your existing sheet is already 90% of what the dashboard needs. Email, branch, location, phone, and names (in legal_first / legal_last) are all there. Your userdirectory.html Apps Script web app will keep working untouched. We just need to add 6 columns and 1 reference tab.

The six steps

1 Add 6 new columns to the data tab

Open the sheet at column BC (the cell right after medical_conditions) and type these 6 headers, one per column:

NEW department
e.g., "IT / Information Technology" — matches Departments tab exactly
NEW title_role
e.g., "Department Lead", "Bishop", "Member"
NEW sub_groups
Comma-separated, e.g., "Videography, Marketing" (optional)
NEW display_name
Greeting name, e.g., "Shahad" or "Bishop Tazayawan"
NEW sync_source
Auto-stamped by script: "Apps Script" or "Manual"
NEW last_synced
Auto-stamped timestamp
Tip: You can skip this manual step — ensureSyncColumns() in the script will add them automatically. Run that first before syncWorkspaceUsers().
2 Paste the Apps Script
  • Open the sheet → Extensions → Apps Script
  • If you already have a project there (the one powering userdirectory.html), create a new script file inside it — don't overwrite what's there. Name the file TNIC_StaffDirectory_Sync.gs
  • Paste in the contents of TNIC_StaffDirectory_SyncScript_v2.js
  • Click + next to Services → add Admin SDK API → Add
  • In Google Cloud Console: APIs & Services → Enable API → "Admin SDK API"
3 Run ensureSyncColumns() once
  • In Apps Script, pick ensureSyncColumns from the function dropdown → click Run
  • Approve permissions when prompted (you must be a Workspace admin)
  • A toast will confirm which columns were added. Safe to re-run.
4 Run syncWorkspaceUsers() once manually
  • Pick syncWorkspaceUsers → Run
  • What will happen:
    • EXISTING rows whose legal_first / legal_last / phone are blank → filled from Workspace
    • EXISTING rows with hand-entered values → never overwritten
    • NEW Workspace users not in the sheet → new row added (email + whatever Workspace has)
    • Every processed row gets sync_source = "Apps Script" and last_synced = now
  • Check the toast message for the count: e.g., "60 processed, 3 new, 12 blanks filled, 45 timestamped only"
5 Set up a daily trigger
  • In Apps Script: Triggers (clock icon) → Add Trigger
  • Function: syncWorkspaceUsers
  • Event source: Time-driven → Day timer → 2am–3am
  • Click Save — you're done. It'll run every night.
6 Add a Departments reference tab

The dashboard's "My Department" card needs to know the Chat Space URL and Dept Page URL for each department. Add one more tab to the same workbook with these columns and 19 rows (one per department):

Safety checks

✓ Will not break userdirectory.html. That web app reads by column header name. Adding columns to the right end of the sheet is a no-op for it.
✓ Will not overwrite your data. The script only writes to legal_first / legal_last / phone when those cells are blank, plus the two metadata columns. Everything else (addresses, insurance, emergency contacts) is never touched.
⚠ Test first. Run syncWorkspaceUsers() once manually before enabling the trigger. Review the counts in the toast. If anything looks wrong, nothing is lost — the existing rows still have all their original data.
✗ Don't run on a snapshot you can't restore. Even though the script is safe, best practice: File → Make a copy of the sheet once before your first run, just in case.

What happens next

Once the sheet is set up and syncing, the remaining dashboard build steps are:

  1. Fill in Department / Title / Display Name for existing staff (one-time manual pass)
  2. Fill in Chat Space URL + Dept Page URL on the Departments tab (19 rows)
  3. Create the AppSheet app — point it at this sheet, use USEREMAIL() filter
  4. Embed the dashboard into Google Sites as the new Home page (4 embeds: Identity, Quick Actions, My Department, Upcoming Events, plus the existing Quick Links + Announcements)
